# Funnel Health Scorecard — Weekly Check-Up

15 minutes every Friday. Track every layer of the funnel. Find the
leak BEFORE you waste a week optimizing the wrong stage.

## The principle: every funnel has exactly ONE biggest leak

This is non-negotiable. At any given moment, your funnel is bottlenecked
by ONE specific stage. Optimizing any other stage produces zero
revenue lift. The scorecard exists to identify which stage is the
bottleneck so you spend next week's energy there.

## The 5-row scorecard

Build this in a spreadsheet. Update weekly. Color-code red / yellow /
green based on your own targets.

| Layer | Metric | This week | Last week | 4-wk avg | Target | RAG |
|---|---|---|---|---|---|---|
| TOFU — visibility | Total social impressions (sum across platforms) | | | | | |
| TOFU — engagement | Sum of likes / reposts / comments across all posts | | | | | |
| TOFU → MOFU | Landing page visits | | | | | |
| MOFU — capture | New lead-magnet signups | | | | | |
| MOFU — engagement | Nurture email open rate (avg across active sends) | | | | | |
| MOFU → BOFU | Replies + DMs from nurture cohort | | | | | |
| BOFU — meeting | Discovery calls booked | | | | | |
| BOFU — close | Deals closed (count) | | | | | |
| BOFU — revenue | $ closed | | | | | |

## How to find your bottleneck

Walk down the rows and find the first one where the conversion rate
to the next row is below your target. That's your bottleneck.

The standard conversion benchmarks (industry-typical for warm
inbound; cold paid traffic is roughly half each):

| From → To | Healthy conversion |
|---|---|
| Social impression → Landing page visit | 1-3% |
| Landing page visit → Lead-magnet signup | 25%+ warm / 8%+ cold |
| Lead-magnet signup → Reply to nurture | 5-15% |
| Nurture reply → Discovery call booked | 30-50% |
| Discovery call → Closed deal | 20-40% |

Each step roughly 10x's the previous in funnel area. By the time
you're at "closed deal," you need ~100,000-300,000 social impressions
to produce one deal at typical conversion rates — which is why
quality of impression matters more than volume.

## The triage table

| If your bottleneck is… | Spend next week on… |
|---|---|
| TOFU visibility (low impressions) | Posting volume + cadence consistency |
| TOFU engagement (low engagement on posted impressions) | Hook quality — rewrite your hook bank |
| TOFU → MOFU (low landing page traffic) | Add the lead-magnet CTA to your top 5 posts + bio |
| Landing page visit → signup (low conversion) | The landing page itself — shorter, clearer headline |
| Signup → nurture engagement (low opens) | Subject lines + sender reputation (deliverability check) |
| Nurture engagement → reply (low replies) | Add an explicit "hit reply" CTA to every email |
| Reply → call booked (low booking) | The reply-to-call handoff — book directly in the reply |
| Call → close (low close rate) | Discovery call mechanics — what you ask, what you propose |

## The "one number" view

If you only check one number weekly: **net new $ closed**. Every other
metric is leading. This is the only lagging indicator that matters.

But — and this is the trap — net new $ closed lags by 2-4 weeks behind
the leading indicators. If you're staring at $0 closed this week,
you're looking at decisions you made (or didn't make) a month ago.
That's why the scorecard exists: to catch the leading indicators
trending wrong BEFORE they become lagging-indicator zeroes.

## The Friday 15-minute ritual

1. **Open the spreadsheet** (4 min).
   Pull this week's numbers from each platform / tool. Total time
   depends on how many platforms — usually 4 minutes if you've
   got bookmarks ready.

2. **Color-code RAG** (2 min).
   Red = below 70% of target. Yellow = 70-100%. Green = at-or-above.

3. **Identify the bottleneck** (2 min).
   Walk down the rows. First red row from the top is the bottleneck.
   If there are no reds, find the row with the worst week-over-week
   trend.

4. **Decide ONE action for next week** (5 min).
   What's the smallest specific thing you can do next week to lift
   the bottleneck? Write it down. Add it to your weekly plan.

5. **Screenshot + archive** (2 min).
   Take a screenshot of the scorecard. Save to `Funnel/YYYY-WW.png`.
   Six months in, you'll have a visual history of what you fixed
   and what trended.

## What kills funnel-health tracking

1. **Tracking everything, acting on nothing.** Scorecards become
   ritual without intervention. Each week MUST produce one specific
   action.
2. **Optimizing too many stages at once.** If you spread your
   week across "fix everything," you fix nothing. One bottleneck,
   one week, one fix.
3. **Quitting too early.** Many fixes need 2-3 weeks to show up in
   the numbers (nurture-email changes especially). Commit to a fix
   for at least 21 days before judging it.
4. **Vanity-metric inflation.** Impressions feel great. Closed deals
   pay the bills. If you're tracking impressions but skipping the
   bottom rows, you're optimizing for the wrong thing.
