# Architecture Decision Records

ADRs capture durable choices whose rationale should survive code changes.

| ADR | Decision |
|---|---|
| [0001](0001-http-and-sqs.md) | Support HTTP and SQS execution paths |
| [0002](0002-service-identity.md) | Use per-service HMAC identity and caller grants |
| [0003](0003-deterministic-before-llm.md) | Prefer deterministic execution before LLM calls |
| [0004](0004-multiple-persistence-models.md) | Use workload-specific persistence |
| [0005](0005-human-on-the-loop.md) | Require operator control for higher-risk actions |
| [0006](0006-constrained-graph-schema.md) | Constrain graph schema and queries |
| [0007](0007-container-and-cloud-targets.md) | Maintain Compose and Cloud Run targets |
| [0008](0008-immutable-baseline.md) | Verify protected runtime files at boot |
| [0009](0009-governed-autonomous-capabilities.md) | Gate autonomous capabilities with fence attestation |
| [0010](0010-codified-tax-categorization.md) | Codified tax categorization with versioned rulesets |
