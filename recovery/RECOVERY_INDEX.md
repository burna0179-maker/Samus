## Foundational principles (final cumulative list)
- Governance NEVER beneath the agent — 3-plane authority mandatory
- Authority flow: root > governance > agents (NEVER reverse)
- Capability tokens, NOT direct permissions
- Demotion fast, promotion slow
- Multi-axis metrics, NOT single score
- Tier 1 Core / Tier 2 Functional separation
- 3 automation modes: Manual / Smart Assist / Full Auto
- Mode hold-timers + hysteresis (prevent flapping)
- Bounded RL only — never unbounded self-modification
- Wrapper-over-replacement pattern
- Score-based vs threshold-snapping resolution
- RedrivePolicy-truth, not name-suffix inference
- Per-route gating, not all-or-nothing fail-closed
- Path-agnostic guidance (plane/lifecycle, not folder paths)
- Local-first + offline-capable + air-gapped option
- Economic layer enables large-scale self-organization
- Six engines required: planning + execution + learning + memory + governance + economic
- Template promotion: experimental → candidate → verified → production
- Fixed-scope guardrails: MAX_STEPS=5, MAX_TOOLS=3, MAX_TEMPLATES=3
- Drift detection: reliability < 0.80 → degrade
- **NO placeholder code, NO TODOs, NO markdown-only specs** (chat 45)
- **Snapshots = governance-approved reality, NOT runtime state** (chat 46)
- **Drift ≠ failure. Drift = deviation from authorized constraints** (chat 45)
- **Snapshots updated ONLY after Parliament approval** (chat 46)
- **Old material = raw intelligence for new architecture** (chat 46)
